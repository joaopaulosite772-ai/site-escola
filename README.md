## 👋 Olá, alunos do JPII!

Sou o **Enrico** e desenvolvi este site para a nossa escola durante o 3 ano. Ele reúne avisos, cronograma de atividades e galeria de vídeos num só lugar.

Peço que cuidem com carinho! 💛

---

## ✏️ Como atualizar as informações

### 1. Encontre os arquivos certos

```
📁 escola-final/
└── 📁 src/
    ├── 📄 App.js    ← aqui você edita os dados (avisos, cronograma, vídeos)
    └── 📄 App.css   ← aqui você muda o visual e as cores
```

> 💡 **Dica:** No `App.js` você encontra os arrays `avisos`, `cronogramaManha`, `cronogramaTarde` e `videos` — edite esses dados para atualizar o site.

---

### 2. Publicar as alterações

Depois de editar e salvar, abra o terminal no VS Code com **Ctrl + \`** e digite:

```bash
npm run deploy
```

Aguarde a mágica acontecer ✨ — quando aparecer **"Published"**, o site já foi atualizado!

---

## 💻 Rodando em outras máquinas

Qualquer computador com **Node.js** instalado consegue rodar o projeto. Basta seguir esses passos:

**1. Clone o repositório**
```bash
git clone https://github.com/joaopaulosite772-ai/site-escola.git
```

**2. Entre na pasta**
```bash
cd site-escola
```

**3. Instale as dependências**
```bash
npm install
```

**4. Rode o servidor local**
```bash
npm start
```

O site abrirá em `http://localhost:3000` 🚀
